# C 工具阶段记录 — 2026-09-16

当前已具备一套可演示、能接入新案例、可保留证明材料的 **C 同语言条件等价原型**。
这里区分代码已实现的能力、用户回传的正式运行结果，以及尚未验证的研究结论。

## 实际工作流程

提供两个受支持的 C 函数和 JSON 契约，声明入口、输入域、返回类型、观察和循环展开界限。
工具检查支持范围，生成 harness 和原生探针，通过安全性检查后寻找条件，再调用现有修改版
ESBMC 验证条件。成功时输出条件、可读报告、机器可读结果、查询及证据归档。

对声明域 D 和所选观察的相等关系 E：

- PARTIAL 给出已认证的充分条件 C：D 且 C 蕴含 E；域内其余输入尚未完整分类。
- EXACT 还认证补集：D 且非 C 蕴含非 E，所以 C 在此域和观察下精确描述等价输入。
- UNKNOWN 不给出认证条件；EMPTY_DOMAIN 明确报告空域。

条件 true 表示整个声明域等价；非空域中的条件 false 表示没有等价输入。
原生样本和 agent 建议只能帮助发现，不能代替这些证明。

## 当前适用范围

通用接口支持受限制的 uint32_t/bool 函数、受界限约束的循环、局部只读表和固定大小数组。
schema 2 数组观察包括返回值和所有最终元素，独立初始化且不允许别名；总初始标量值不超过四个，
数组元素计入总数。具体限制见 [C 接口](C_SCALAR_TOOL.md) 和 [快速使用](C_TOOL_QUICKSTART.md)。

缓存案例另有人工审阅的状态适配器与显式 invariant，需要初始化和保持性证明。
这不等于通用 C 接口支持任意全局状态、堆、I/O、并发或任意调用序列。
agent 接口是提案与反馈协议；自主模型调用和 invariant 自动合成尚未实现。

以下正式运行结论来自用户回传；原始远端归档尚未在此任务中独立审阅。

| 节点 | 回传结果 | 所支持的判断 |
|---|---|---|
| 统一 C 演示 | READY 8/8 | 标量、查表、数组、缓存等现有案例可通过统一展示流程运行 |

这些结果支持“已有可用的 C 原型”这一阶段判断。它们不证明任意 C 可处理，也不是独立盲测、
十个独立程序的成功率或跨语言复用结论。全新主机复现、独立选取的案例和原始证据审阅仍待完成。

## 当前需要解决的问题

用户随后提供的逐项数据已经定位：所有运行都是五次查询，只有全 32 位域两次在等价查询上超时。
24 位成功流程的平均耗时约 35.9 秒，包含多次查询，不能与单次 30 秒上限直接比较。
当前证据指向单次后端查询成本；具体求解阶段尚不清楚。另开 30/120 秒预算比较，保留原实验、
源码和引擎；即使更长预算成功，也只说明这个案例对预算敏感，不能宣称求解器得到了优化。
